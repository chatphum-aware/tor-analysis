## รูปแบบ source ของเอกสารนี้ (PDF)

เอกสารที่ให้มาเป็น **PDF ที่ดึงข้อความออกมาได้** ดังนั้นทุก source ต้องเป็นแบบนี้:

- `kind`: `"text_page"` เสมอ
- `page`: เลขหน้าตามมาร์กเกอร์ `[หน้า N]` ที่คั่นอยู่ในข้อความ
- `ref`: **null เสมอ** (ฟิลด์นี้มีไว้สำหรับเอกสาร Word/Excel ที่ไม่มีเลขหน้า
  ถ้าใส่มาพร้อม `page` จะถือว่าผิดรูปแบบและถูกปฏิเสธ)
- `quote`: ข้อความต้นฉบับจากหน้านั้นที่คัดมาตรง ๆ

ตัวอย่าง: `{"kind": "text_page", "page": 3, "ref": null, "quote": "วงเงินงบประมาณ 7,672,800.00 บาท"}`
