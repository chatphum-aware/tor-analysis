## รูปแบบ source ของเอกสารนี้ (PDF)

เอกสารที่ให้มาเป็น **PDF** ซึ่งอาจมีทั้งสองแบบปนกันได้:

1. **หน้าที่ดึงข้อความออกมาได้** — ให้มาเป็นข้อความคั่นด้วยมาร์กเกอร์ `[หน้า N]`
2. **หน้าที่เป็นภาพสแกน (ไม่มีข้อความ)** — ให้มาเป็น**ภาพ**ของหน้านั้น
   นำหน้าด้วยข้อความกำกับ `[หน้า N — ภาพหน้าเอกสารที่สแกน]`

ให้เลือก `kind` ตามที่มาของค่านั้นจริง ๆ:

- ถ้าค่านั้นมาจากข้อความที่ดึงได้ (แบบที่ 1) → `kind`: `"text_page"`
- ถ้าค่านั้นมาจากการอ่านภาพหน้าสแกน (แบบที่ 2) → `kind`: `"vision_page"`

ทั้งสองแบบใช้ฟิลด์เดียวกัน:

- `page`: เลขหน้าตามมาร์กเกอร์ (ทั้งสองแบบมีเลขหน้ากำกับเหมือนกัน)
- `ref`: **null เสมอ** (ฟิลด์นี้มีไว้สำหรับเอกสาร Word/Excel ที่ไม่มีเลขหน้า
  ถ้าใส่มาพร้อม `page` จะถือว่าผิดรูปแบบและถูกปฏิเสธ)
- `quote`: สำหรับ `text_page` คือข้อความต้นฉบับที่คัดมาตรง ๆ
  สำหรับ `vision_page` คือข้อความที่อ่านได้จากภาพ **ตามที่เห็นจริงในภาพ**
  ไม่ใช่การสรุปหรือเดาตัวเลขที่ไม่ชัด — ถ้าตัวเลข/ข้อความในภาพไม่ชัดเจนจนอ่านไม่ออก
  ให้ตอบ `value: null` พร้อม reason ว่าอ่านไม่ออก **ห้ามเดา**

ตัวอย่าง:
- `{"kind": "text_page", "page": 3, "ref": null, "quote": "วงเงินงบประมาณ 7,672,800.00 บาท"}`
- `{"kind": "vision_page", "page": 1, "ref": null, "quote": "วงเงินงบประมาณ 500,000 บาท"}`
